# ACH Guatemala · Prototipo de visibilidad

Landing informativa orientada a presentar Acción contra el Hambre Guatemala y facilitar alianzas y contacto.

## Publicar en GitHub Pages

En Settings → Pages, selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guarda la configuración.

No necesita compilación ni instalación de dependencias. Los enlaces a recursos usan rutas relativas compatibles con GitHub Pages.

## Contenidos del prototipo

- Presentación institucional y cinco componentes de intervención.
- Cuatro espacios vacíos para fotografías; no contiene fotos de personas.
- Mapa orientativo con seis municipios documentados, filtro por año de fuente y referencias públicas. No constituye un inventario de cobertura vigente.
- Espacios para Facebook, Instagram, LinkedIn y YouTube; enlaces pendientes de confirmar.
- Enlace al formulario institucional de contacto.

## Fuentes del mapa

- ACH, Informe de línea de base, agosto 2025, tabla 1: Huehuetenango, Malacatancito, Chiquimula y Jocotán. https://accioncontraelhambre.org.gt/wp-content/uploads/2025/11/ACH_Informe-LineaBase-Proyecto-ECHO-20250909.pdf
- ACH, licitación de alcantarillado, septiembre 2026: Flores y San Benito, Petén. https://accioncontraelhambre.org/es/licitaciones-tenders-appel-doffres
- Base cartográfica Natural Earth, dominio público; localización aproximada de cabeceras, sin límites municipales. https://www.naturalearthdata.com/

Los contenidos y perfiles sociales deben validarse antes de su difusión institucional. Edita index.html para modificar textos, fotografías o enlaces; app.js controla los filtros del mapa.
